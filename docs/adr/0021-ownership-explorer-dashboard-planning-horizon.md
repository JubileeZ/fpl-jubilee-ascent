# Ownership Explorer is the live dashboard; Planning Horizon is Start–End max 6

Product UI is Ownership Explorer only. Transfer Plan stays CLI MILP (`commands.solve`), not a tab. Planning Horizon is inclusive [Horizon Start, Horizon End], length 1–6 (default End = min(Start+5, 38)). Start is any unfinished Gameweek from the earliest unfinished through 38 (live deadline-passed allowed; finished never Start). Start/End re-slices the Full-Season Dashboard Data Contract in the browser. Dashboard Refresh is in-page FPL ingest plus Comparison Slate Project; `commands.dashboard` starts HTTP immediately and does not ingest or project on process start. A live unfinished Gameweek uses the full Gameweek Projection. Shared clamp max 6; solve keeps `--target_gw` (Start) and `--horizon` (length). Expected Role Rebuild and Dual-Source adapters are unchanged (ADR 0016).

**Status:** Accepted. Supersedes ADR 0018’s two-tab UI, 1–5 lookahead from `is_next`, and deadline-passed exclusion. ADR 0018 Mix vs Mix, no Squad Builder, no Season Window / Score Mode in product Explorer, Primary Model for Explorer still stand. ADR 0019 Modified FDR unchanged. ADR 0022 supersedes the Expected Role Table refuse-to-Project clause (was “until a later ADR reopens 0016”).

**Considered:** Repair the Transfer Plan tab; End through GW38; lock Start to `is_next` or only the earliest unfinished GW; block process start on Project; Start/End re-project or full Refresh; in-play trim of the live GW. Rejected: tab is not the live product; 38 is Full-Season Window; `is_next` drops the live week; locking Start prevents the two dropdowns; blocking start contradicts open-then-Refresh; picker must be instant; no in-play remaining-fixtures grain.

**Consequences:** `dashboard/plan.js` and `/api/transfer-plan` are not product UI. `MAX_PLANNING_HORIZON` is 6. Feature Contract does not refuse without an Expected Role Table (ADR 0022). Assume 90 is a view-only Explorer toolbar toggle for all Players (not Feature Contract).

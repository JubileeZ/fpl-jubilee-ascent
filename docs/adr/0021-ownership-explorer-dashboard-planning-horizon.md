# Ownership Explorer is the live dashboard; Planning Horizon is Start–End max 6

Product UI is Ownership Explorer only. Transfer Plan stays CLI MILP (`commands.solve`), not a tab. Planning Horizon is inclusive [Horizon Start, Horizon End], length 1–6 (default End = min(Start+5, 38)). Start is any unfinished Gameweek from the earliest unfinished through 38 (live deadline-passed allowed; finished never Start). Start/End re-slices the Full-Season Dashboard Data Contract in the browser. Dashboard Refresh is in-page FPL ingest plus Primary Projection Model Project; exclusive with Dream Team Solve. `commands.dashboard` starts HTTP immediately; Open projects Primary from disk when JSON is stale, else paints last JSON. A live unfinished Gameweek uses the full Gameweek Projection. Shared clamp max 6; solve keeps `--target_gw` (Start) and `--horizon` (length). ADR 0025 retires Expected Role Rebuild and Dual-Source adapters; Explorer reports xMins, not Role.

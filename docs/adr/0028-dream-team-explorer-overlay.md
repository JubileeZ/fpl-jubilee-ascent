# Dream Team is an Explorer overlay; Transfer Plan stays CLI

Ownership Explorer needed a budget-constrained “best 15” highlight without becoming a plan you play. In-page **Solve** runs MILP for a **Dream Team**: frozen legal 15 for the Planning Horizon, spend ≤ ITB + Selling Prices (£100.0m if no User Squad), Primary Projection Model, `xmin_lb` 0. Paint chart + table badge `Dream` only. Session-only IDs; clear on horizon, Primary Model, or Refresh. No Available Chip check (guide, not a Booked Chip). Squad Board / Squad What-If stay the User Squad. Dashboard Data Contract still has no Transfer Plan JSON and no Dream Team IDs. Assume 90 stays view-only.

**Status:** Accepted. Amends ADR 0027’s “Re-solve stays CLI” only for this overlay button. Transfer Plan, Force Keep/Ban, applied Hits, and Load MILP Squad stay CLI / not on the pitch. Mix vs Mix stays undrawn.

**Considered:** Transfer Plan scoring 15 as the highlight; `--preseason` £100.0m whenever a User Squad exists; badge `WC` / Wildcard 15; load onto Squad What-If; filter or dim the pool; embed IDs in dashboard JSON; Solve inside Refresh or project-on-open; gate on Available Chip; Champion-only datasource; `xmin_lb` 100. Rejected: FT-limited plan is mostly Owned; £100.0m ignores current budget; `WC` claims a chip; pitch load is a sandbox 15; filter/dim hides the pool; persist/auto-solve contradicts session overlay and Refresh = ingest+project; chip gate blocks a guide; Champion-only disagrees with Explorer numbers; minute floor drops cheap enablers.

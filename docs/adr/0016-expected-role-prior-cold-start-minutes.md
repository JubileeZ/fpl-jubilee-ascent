# Expected Role Prior is the Feature Contract Cold-Start minutes prior

Production Cold-Start used last-season `minutes_if_appearance` and 78/18 defaults. That misses new XIs and club-changers. Feature Contract now takes Participation State and conditional minutes from the committed Expected Role Table (Expected Role Prior, Draft Availability overlays, then Availability Override, then API chance). Event Rates stay Prior-Season Seed. Appearance Blend is per-player, weight 0 through 1 appearance, 100% current-season at 5. Missing rows take Out of Contention. Projection never scrapes; Stage 1 adapters write Dual-Source Lineup Signals (predicted XI + nailed markers) and the table. Websites may change; signals and conflict rules stay. When data refresh finds a missing or other-season table, ask Expected Role Rebuild vs defer (agent chat and `--rebuild-roles` / `--keep-roles`; no flag refuses). Defer still ingests the FPL API; Feature Contract refuses until a this-season table exists. Do not scrape silently. Do not reuse last season's table.

**Status:** Superseded by ADR 0022 for Feature Contract minutes, Event Rate clock, Appearance Blend 1→5, and table-gated Project. Dual-Source Lineup Signals and Expected Role Table as a Role registry still stand.

**Considered:** Dashboard-only minutes; calendar GW5 flip; live scrape inside Feature Contract; keep blend 3→8; two minutes brains (role `p_*` unused); deferral keeps last season's table; Out of Contention or seed-minutes fallback while deferred. Rejected: dashboard would disagree with the solver; calendar GW5 treats unused players as full live; scrape dies when HTML moves; 3→8 delays the live mix the User asked for; last year's XI is not this year's prior.

**Consequences:** `build_features` copies table `p_*` / `mins_if_*` onto Feature Contract columns and derives `appearance_probability` and `minutes_if_appearance`, then Appearance-Blends toward current-season observations. Champion, solver, report, and Ownership Explorer share that xMins. Research Stage 1 remains the authoring path. Expected Role Table carries season identity.

# This-Season Evidence ends Cold-Start; in-season rates ignore last year's player

Feature Contract still uses Recency-Weighted Prior Shrinkage on current-club Club Fixtures (decay 0.95, strength 4). Cold-Start (no This-Season Evidence) uses per-player Prior-Season Seed else last-season Position-Price. This-Season Evidence is global: one this-season `player_performances` history row (`element_summary` history: minutes, starts, or recorded DNP) switches every Player. After that, observations and the shrink target are this-season Position-Price only; empty tenure is that pool, not last year's player. `commands.backtest`, Historical Promotion Gate, and Transfer Plan Walk-Forward replay the same clock at each historical deadline.

**Status:** Accepted. Supersedes ADR 0022 in-season Prior-Season Seed as shrink target and empty-tenure prior. Club Fixture grain, missing-history-is-not-DNP, no Role minutes, no table-gated Project, next-GW 0% chance only, Availability Override off still stand (0022). ADR 0010 snapshot and no-third-party-xP still stand; in-season shrink target is this-season Position-Price, not per-player last season. Reopens ADR 0020 walk-forward seed-through-GW19 assumption.

**Considered:** Hardcoded Position defaults at empty league; last-season Position-Price pool with this-season likelihood only; per-player first Club Fixture as the switch; GW1-deadline calendar switch; evaluate old 0022 blend while shipping this rule. Rejected: Q8 wants last-season player seed until the season has started; Q2/Q5 forbid in-season last-year player minutes; Q7 picked global not per-player; promotion must rank the shipped clock.

**Consequences:** First history row of a season (including a 0-minute DNP) ends last-year minutes for Sunday clubs that have not played. Promotion `cold_start` window GW1–4 is true Cold-Start only while that season's history is still empty. Existing 2025-26 walk-forward companions used 0022 seed in-season; they are not this clock.

# Straight-Line Horizon-Locked Decision Tree Planner with Pre-Deadline User Squad Origin

Visual branching Decision Tree Planner aligns with MILP solver and Planning Horizon. Freely-draggable staggered node layout replaced with strict matrix grid: columns map strictly to Gameweeks (Col 0 = Current User Squad origin, Col 1..H = Gameweeks), rows map to branch lanes. Nodes locked in place (`nodesDraggable=false`). Primary plan runs horizontally along Row 0; branch split at Box K drops to next row lane at Col K+1 and extends horizontally through Horizon End. Canvas box depth strictly matches Planning Horizon; increasing/decreasing horizon appends/trims boxes across all active branches. Each box maintains dual state: `solverRecommendation` (cached MILP solution) and `lineup` (manual pitch adjustments). Manual edits trigger `✏️ Custom` badge and `↩ Reset to Solver` button for instant 1-click reversion without re-solve. Per-box `⚡ Solve` invokes Highs MILP from Box K-1 squad and bank state across remaining horizon (Horizon End - K + 1), isolating updates to active branch lane without mutating sibling branches. Origin Root Node represents live pre-deadline User Squad entering Horizon Start from `user_picks.parquet`. Header `#plan-horizon` and planner store synchronized bi-directionally.

**Status:** Accepted.

**Considered:** Free-form node dragging (rejected: disrupts timeline readability and causes accidental node displacement during pitch interaction); dynamic staggered-Y child averaging (rejected: breaks horizontal continuity); single-node incremental branching (rejected: causes horizon disconnect where canvas displays fewer gameweeks than configured horizon); prompt on every branch split (rejected: standard decision tree semantics branch from step N into step N+1).

**Consequences:** `DecisionTreeCanvas.jsx` enforces matrix layout and locked dragging. `usePlanStore.js` manages horizon synchronization, full-chain branch splitting, and `solverRecommendation` state with instant revert. `PlanNode.jsx` and `RootNode.jsx` display solver vs custom state badges and per-box solve triggers. `commands/dashboard.py` default plan generator builds full horizon chains.

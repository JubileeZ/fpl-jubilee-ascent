# Transfer Plan is a third dashboard view, Champion-only

Product Transfer Plan is a separate dashboard tab from Interactive Squad Builder. It renders the MILP result over a Planning Horizon (default 6 from the next unfinished gameweek) using the Model Champion and Official Fixture Difficulty. It does not load Canonical Preseason Chip Path CSVs or Dual-Vector research xP.

Rejected: replacing Squad Builder; driving MILP from the header Primary Projection Model; showing Dual-Vector and product xP on one screen; viewer-only without Re-solve. Booked Chips are a per-gameweek calendar (at most one chip). The UI labels undiscounted Gameweek Projection xP and decayed Solver Objective separately.

## Method

Rate **season role security when available**, separate from GW1 World Cup rest.

| Tier | Code | Start share (fit) | Use in next analysis |
| --- | --- | --- | --- |
| **Nailed** | N | ≥ ~85% | Core shortlist — keep |
| **Regular / preferred** | R | ~60–84% | Keep; flag rotation risk |
| **Battle / rotation** | B | ~30–59% | Drop unless differential thesis |
| **Reserve / cover** | X | < ~30% or flagged out long-term | Out of scope |

**Weights**: prior-season minutes → manager/system continuity → new signing displacement → injury/transfer flags.  
**8 new managers** (Rose, Alonso, Sage, Iraola, Maresca, Glasner, Arbeloa, O’Neil) → higher B-tier uncertainty.  
**Promoted** (COV / HUL / IPS): Championship roles only; treat R as provisional.

3. Apply **GW1 rest/injury flags** only for opening-week picks — do not demote season N-tier for World Cup recovery alone.

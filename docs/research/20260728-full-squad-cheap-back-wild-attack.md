| Player | Pos | £ | Own% | 25/26 | Nailed? | Case |

| Isak | FWD | 9.0 | 11.8% | **8 starts** · 3G1A · 41pts | **R→N lean** | Post-Salah #9; pens likely; injury-scarred debut |

**Cost of triple = £23.5m** (uses full 3-LIV quota).

### Why it can work
1. Best MW1–5 FDR in the league (2.6).  
2. Iraola publicly prioritising Isak + Wirtz bounce after poor first seasons.  
3. Salah exit → Isak pen path (unlike 25/26).  
4. Szobo already consensus mid-price; Wirtz+Isak are lower-owned differentials.  
5. Liverpool top-4 odds 4/9 → attack should generate volume.

### Why it is fragile
1. **Concentration:** one tough run / midweek Europe blanks three assets.  
2. **Isak minutes history:** only 8 PL starts last season — fitness is the real bet.  
3. **Wirtz** is the soft seat: R-tier, new-manager chemistry, wide-signing threat.  
4. **Opportunity cost:** £23.5m ≈ Bruno (£12) + João Pedro (£7.5) + Xhaka (£5.5) − £1.5, *or* most of a Haaland-shaped hole.  
5. Club limit blocks Kerkez / Virgil hedge.

**Research call:** Keep the gamble only if you treat **Wirtz as the swing piece**. Optimized core = **Szoboszlai + Isak**; move Wirtz money to **Bruno**.

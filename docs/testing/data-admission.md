Version 1; synthetic admission only. Empirical approval/authority registry pending Phase 8. Native rules registration pending Phase 2; forecast/replay integration pending Phase 3. No empirical admission or promotion claim.

## Public boundary

`assess_origins(request, catalog)`: one report per requested origin in request order; selected sources, excluded-source reasons, requirement/availability cells, issue readiness and causal input digest. Required fields only; no permitted-limitation default. Assistant Manager inapplicable under registered `no_assistant_manager` synthetic chip policy; no unrestricted chip claim.

`require_input` / `verify_input`: recheck synthetic issue data, effective policy and retained authority; input digest excludes scoring sources and outcomes. `require_admitted` / `verify_admitted`: recheck completed synthetic evidence; `evidence_digest` binds full request and catalog. Future consumers must revalidate capabilities. Public record construction alone proves nothing.

Catalog: SHA256-keyed bytes. Pinned synthetic authority: version, season/GW scope, universe, eligibility start, seed mapping, component records. Authority lists hashes of canonical source manifests; retained manifest bytes bind source metadata, timestamps, table hash and content hash. Parent references authority. Input identity projects authority policy and selected input metadata without future scoring-manifest hashes; adding scoring authorization preserves issue capability. Input and scoring packages retained by content hash. Selection: validate each retained package before selecting latest eligible source per role; reject a supplied normalized table that differs from the selected package. Rejected candidates retain reasons; tied latest candidates unavailable. Scoring defects remain separate from issue readiness and issue identity. Input source capture and publication uncertainty strictly before cutoff; scoring source after deadline. Canonical uncompressed JSON only; raw and decompressed hashes equal. Metadata and hashes prove byte consistency, not source authenticity, independent population truth or historical causality.

`strict_load`: declared season/GW, source path/hash and scope-bearing parent manifest chain required before reader invocation; unknown scope and declared 2026-27 GW6+ rejected. Source path/hash must occur in parent scopes. No amendment mechanism; path/season assertions require trustworthy acquisition metadata. No network in tests.

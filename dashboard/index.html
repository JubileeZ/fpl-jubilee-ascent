Model Projection Methodology & Pipeline

How raw FPL statistics, expected minutes, and matchup matrices calculate projected points for every player.

Active Champion: -
Layer 1

Minutes & Availability

Stochastic start probability estimation with DNP suppression.

xMins = P(start) · E[mins|start] + P(sub) · E[mins|sub]

Models starting security using trailing start windows (ADR 0035), rolling minutes history, press conferences, and official status news.

Layer 2

Rates & Shrinkage

Per-90 event rates with defensive xG empirical shrinkage.

Rate = (Σ Stat + K · Mean) / (Σ Mins + K)

Champion applies pseudo-minutes shrinkage (K=2400 for DEF xG per ADR 0055). Poisson clean sheet rate is derived from opponent expected goals.

Layer 3

Matchup Scaling

Opponent difficulty via Modified FDR and Matchup Share.

Scaled Rate = Base Rate · Matchup Share(club, opp)

Uses Modified FDR difficulty ratings and Calibrated Matchup Share (ADR 0040) to scale clean sheet and attacking returns by opposition quality.

Layer 4

Scoring Matrix

Exact deconstruction across 8 rulebook components.

Total xP = Σ(Minutes, Goals, Assists, CS, GC, Defcon, Saves, Bonus)

Position-specific scoring weights (DEF goal 6 pts, MID goal 5 pts, FWD goal 4 pts) guarantee mathematical traceability.
